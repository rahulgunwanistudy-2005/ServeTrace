# Languages

ServeTrace ships in English only. Version 1.1 adds the plumbing for a second language and
deliberately does not add one.

## What exists

- **One file of copy.** Every string a person reads lives in `frontend/src/lib/copy/en.ts`.
  Routes and shared components import from `$copy/en`. A vitest
  (`src/lib/copy/index.test.ts`) scans `src/routes` and `src/lib/ui` for text written
  straight into markup or into `aria-label`, `title`, `placeholder` and `alt`, and fails if
  it finds any. Its allowlist holds only text that is not language (the product name,
  `CPLR`, units).
- **A locale registry.** `src/lib/copy/index.ts` exports `locales` (`{ en }` today),
  `t(key, ...args)` with a typed `CopyKey` union of every dotted key, and
  `resolveLocale(search, stored)`: `?lang=` first, then the stored preference
  (`localStorage`, key `servetrace.locale`), then English. A code that is not registered
  falls through to English, never to a blank page.
- **Documents.** The evidence packet, the draft affidavit and the advocate report are
  rendered on the server from `backend/app/documents/copy.py` and the Jinja2 templates.
  They are English, and a court filing in New York City Civil Court is filed in English.

## Adding a language

1. Copy `en.ts` to `<code>.ts` and translate it. `locales` is declared with
   `satisfies Record<string, Copy>`, so the compiler refuses a file that misses a key or
   changes a template's arguments.
2. Register it in `locales`.
3. Switch components from `$copy/en` to the active locale (via `t` or a store that
   resolves `currentLocale()`), one route at a time.
4. Run the gates. The hard-coded-copy test keeps new strings out of markup.

## Before any second language ships

**Legal-facing copy must be reviewed by a qualified native speaker with knowledge of New
York civil procedure** — someone able to say whether a translated sentence still means
exactly what the English one means. That covers the result headlines and their limitation
line, the deadline clock, the "what this means / what it doesn't" text, every next step,
the privacy page and every disclaimer. A mistranslated deadline or a sentence that turns
"your data conflicts with the affidavit" into "the server lied" could hurt the person
reading it, and no automated check catches that.

Machine translation is out of scope for this reason. The draft supporting affidavit is
not translated at all: it is filed with the court in English, and a translated view of it
would need the same review and a clear label that only the English text is filed.
